# Mulheres e Ciência: dignidade e reconhecimento

Projeto de uma reportagem e quiz interativo voltado para a apresentação do tema "Mulheres e ciência: dignidade e reconhecimento à luz da magnifica humanitas" no congresso da PUC Goiás.

## Objetivo

Este projeto tem como finalidade apresentar, de forma acessível e visual, a importância das mulheres na ciência, destacando questões de dignidade, visibilidade e reconhecimento na sociedade e na academia.

## Conteúdo

- Reportagem sobre a história, os desafios e os avanços das mulheres na ciência
- Quiz interativo para reforçar o conhecimento adquirido
- Apresentação temática em formato de site estático

## Estrutura do projeto

- `index.html`: página inicial com acesso à reportagem e ao quiz
- `paginas/reportagem.html`: conteúdo da reportagem
- `paginas/quiz.html`: quiz interativo
- `servico/Quiz.mjs`: lógica do quiz
- `css/` e `js/`: arquivos de estilo e scripts

## Como executar

1. Abra o projeto em um navegador diretamente pelo arquivo `index.html`, ou
2. Rode o servidor local:

```bash
python3 -m http.server 8000
```

Depois acesse:

```bash
http://localhost:8000
```

Ou acesse a versão publicada no GitHub Pages:

[Visualizar projeto no GitHub Pages](https://paradoxisreal.github.io/Congresso-Mulheres-e-ciencia-dignidade-e-reconhecimento-a-luz-da-Magnifica-Humanitas/index.html)
